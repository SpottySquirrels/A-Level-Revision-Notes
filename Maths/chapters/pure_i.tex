\section{Quadratics} \label{quadratics}
    A quadratic is an expression in the form $ax^2+bx+c$, for some real constants $a$, $b$ and $c$.
    The solutions for a quadratic in the form $ax^2+bx+c=0$ are given by the quadratic formula:
    \begin{equation} \label{eq:quadratic_formula}
        x=\frac{-b\pm\sqrt{b^2-4ac}}{2a}
    \end{equation}
    
    \subsection{The Discriminant}
        From the quadratic formula (equation \ref{eq:quadratic_formula}), we can see that if $b^2-4ac<0$, the square root will give an imaginary number, meaning that the equation has no real roots.
        This part of the formula is called the discriminant, written $\Delta$:
        \begin{equation}
            \Delta=b^2-4ac
        \end{equation}

        Using the discriminant, we can tell whether a quadratic has one distinct real root, two distinct real roots, or no real roots (two complex roots).
        \begin{itemize}
            \item \textbf{No real roots:} if $\Delta<0$, then $\sqrt{\Delta}\notin\R\implies x\notin\R$, so there are no real roots.
            \item \textbf{One distinct real root:} if $\Delta=0$, then both values of $x$ are equal, so both of the roots are the same ($x=\frac{-b}{2a}$), thus the quadratic has only one distinct real root.
            The Fundamental Theorem of Algebra says that for an $n$th degree polynomial, there exists $n$ roots, so the single distinct root is technically two roots with the same value.
            \item \textbf{Two distinct real roots:} if $\Delta>0$, then the value of $+\sqrt{\Delta}$ is not the same as the value of $-\sqrt{\Delta}$, so the two roots are both real and different (since $a\neq-a\;\forall\;a\in\R\setminus\set{0}$ and $\sqrt{\Delta}\neq0$ if $\Delta>0$), giving two distinct real roots.
        \end{itemize}

    \subsection{Factorising}
        A quadratic $ax^2+bx+c=0$ can be factorised into a pair of binomials $a(x-\alpha)(x-\beta)=0$, where $\alpha$ and $\beta$ are the roots of the polynomial.
        To find $\alpha$ and $\beta$, find two values $m$ and $n$ that multiply to $ac$ and sum to $b$.
        With these values, the expression $ax^2+bx+c$ can be rearranged into $(ax^2+mx)+(nx+mn)$.
        From these brackets, find a common value to factor out of both, and then it will simplify to a pair of binomials.

        This can then be used to get the roots.
        Set each bracket individually to 0, and then solve for $\alpha$ or $\beta$.

    \subsection{Quadratic Inequalities}
        A quadratic inequality is an expression one of these forms:
        \begin{itemize}
            \item $ax^2+bx+c>0$
            \item $ax^2+bx+c<0$
            \item $ax^2+bx+c\ge0$
            \item $ax^2+bx+c\le0$
        \end{itemize}
        Because the inequality does not set the quadratic equal to a value, but instead allows it to be equal to a range of values, the value of $x$ can also be one in a range.
        
        To solve quadratic inequalities, first find the roots of the quadratic, $\alpha$ and $\beta$.
        Then, look at a graph of the function to find where the value of the quadratic is less than/greater than 0.

        For example, let $p(x)=x^2-4x-5$.
        The roots of $p(x)=0$ are $-1$ and 5, so we can then look at a graph to find where $p(x)>0$, where $p(x)<0$, where $p(x)\ge0$, and where $p(x)\le0$.

        On the graph below, the graph is shaded red where $p(x)>0$ (where the line is above the $x$-axis).
        This means that the values of $x$ are anywhere outside of the interval from $-1$ to 5.

        If the inequality was $p(x)\ge0$, the solution would alos have $\le$ and $\ge$ symbols -- $x\le-1$ or $x\ge5$.

        Thus, for $p(x)\le0$, $-1\le x\le5$.

        The set of values that satisfy an equation or inequality is called the solution set.

    \subsection{Set-Builder Notation}
        A set of values can be written using set-builder notation as:

        \begin{equation}
            \set{x\in S:\phi(x)}
        \end{equation}

        Where $\phi(x)$ is a condition which can be true or false, based on the value of $x$, and $S$ is a set containing $x$.
        The set represents the set of all values $x$ in the set $S$ that satisfy $\phi(x)$.
        The `$\in S$' part can be omitted if it is obvious which set is being talked about, usually $S=\R$.
        
        An example of set-builder notation would be the set of all integers greater than 2:

        \begin{equation}
            \set{x\in\Z:x>2}
        \end{equation}

        This would be equivalent to the set:
        
        \begin{equation}
            \set{3,4,5,\cdots}
        \end{equation}

        However, the condition $\phi(x)$ can be more complex; $\phi$ (I have removed the `$(x)$' for simplicity, but $\phi$ has the same meaning as $\phi(x)$) can be built from other conditions $\chi$ and $\psi$ using boolean logic:

        \begin{align}
            \chi\;\text{and}\;\psi&:\;\chi\wedge\psi \\
            \chi\;\text{or}\;\psi&:\;\chi\vee\psi \\
            \text{not}\;\psi&:\;\lnot\,\psi
        \end{align}

        Alternatively, they can be written using unions and intersections of multiple sets:

        \begin{align}
            \set{x:\chi\wedge\psi}&=\set{x:\chi}\cap\set{x:\psi} \\
            \set{x:\chi\vee\psi}&=\set{x:\chi}\cup\set{x:\psi} \\
            \set{x\in S:\lnot\,\psi}&=S\setminus\set{x:\psi}
        \end{align}

        Set-builder notation can be used to represent solution sets.
        For example, the set of values that satisfy $\alpha<x<\beta$ can be written:

        \begin{equation}
            \set{x\in\R:\alpha<x<\beta}
        \end{equation}

        The set of values that satisfy $x<\alpha$ or $\beta<x$ (where $\alpha<\beta$) can be written:

        \begin{equation}
            \set{x\in\R:(x<\alpha)\vee(\beta<x)}=\set{x\in\R:x<\alpha}\cup\set{x\in\R:\beta<x}
        \end{equation}

        Alternatively, this set also represents all values of $x$ in $\R$ that are not in the closed interval $\left[\alpha,\beta\right]$, thus could be written $x\in\R\setminus\left[\alpha,\beta\right]$.

        For a quadratic $p(x)=0$, the solution set would not require set-builder notation, since there are only one or two values, so it can be written $\set{\alpha,\beta}$.
        If there are no real roots, the set of real roots is empty, and can be written as the empty set $\emptyset=\set{}$.

    \subsection{Completing the Square} \label{completing_the_square}
        \begin{theorem}[Completing the Square]
            A quadratic in the form $ax^2+bx+c$ can be written in the form $a(x+m)^2+n$, where $m=\frac{b}{2a}$ and $n=-\frac{b^2}{4a}+c$:
            \begin{equation}
                a^2+bx+c=a\left(x+\frac{b}{2a}\right)^2-\frac{b^2}{4a}+c
            \end{equation}
        \end{theorem}
        \begin{proof}
            We will begin by factoring $a$ out of the first two terms of the original quadratic to get:
            \begin{equation}
                ax^2+bx+c=a\left(x^2+\frac{b}{a}\right)+c
            \end{equation}
            Now, the $\left(x^2+\frac{b}{a}\right)$ part can almost be factorised into $\left(x+\frac{b}{2a}\right)^2$, however expanding that will give an extra $\left(\frac{b}{2a}\right)^2$ term.
            This means that it can be rewritten as:
            \begin{equation}
                \left(x^2+\frac{b}{a}\right)=\left(x+\frac{b}{2a}\right)^2-\frac{b^2}{4a^2}
            \end{equation}
            This can be put back into the formula to get:
            \begin{equation}
                ax^2+b+c=a\left(\left(x+\frac{b}{2a}\right)^2-\frac{b^2}{4a^2}\right)+c
            \end{equation}
            Moving the $\frac{b^2}{4a^2}$ term out of the brackets (and thus multiplying by $a$):
            \begin{equation}
                ax^2+bx+c=a\left(x+\frac{b}{2a}\right)^2-\frac{b^2}{4a}+c
            \end{equation}
        \end{proof}

    \subsection{Quadratic Turning Points}
        A quadratic $p(x)$ is a parabola, so has a turning point where $\frac{dp}{dx}=0$.
        This can be found in one of two ways:
        \begin{itemize}
            \item \textbf{Completing the Square:} use completing the square (see section \ref{completing_the_square}) to put the quadratic in the form $a(x-m)^2+n$.
            This is the same as using graph transformations to move the parabola $ax^2$ (which has a turning point $(0,0)$) right by $m$ (subtract $m$ from the $x$ value), and then moving it up by $n$ (add $n$ to the overall value).
            This means that the turning point is going to be $(0,0)$, moved right by $m$ and up by $n$, which is $(m,n)$.
            Substituting in the values for the quadratic $ax^2+bx+c$, the turning point is $\left(-\frac{b}{2a},-\frac{b^2}{4a}+c\right)$.
            \item \textbf{Differentiation:} since the turning point is the point where $\frac{dp}{dx}=0$, it can be found by finding the derivative of $p(x)$, which (for $p(x)=ax^2+bx+c$) is $2ax+b$.
            Then, set $2ax+b$ to 0, giving $x=\frac{b}{2a}$.
            This can then be substituted into $p(x)$ to give the $y$-coordinate ($y=p\left(\frac{b}{2a}\right)$).
        \end{itemize}

    \subsection{The Sine Rule}
        \begin{theorem}[Sine Rule] \label{thm:sine_rule}
            The sine rule states that, for a triangle with sides $a$, $b$, $c$, and angles $A$, $B$, $C$ opposite to the corresponding side ($A$ opposite to $a$, etc.), the following holds:
            \begin{equation}
                \frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}
            \end{equation}
        \end{theorem}
        \begin{proof}
                We will begin by drawing the triangle described in theorem \ref{thm:sine_rule}, with a line with length $h$ from $C$ to $AB$, meeting $AB$ at a right angle:
            \begin{figure}
                \begin{center}
                    \begin{tikzpicture}[x=15mm, y=15mm, >=stealth]
                        \draw (-3,2) -- (2,3) -- (1,0) -- (-3,2);
                        \draw[dashed] (1,0) -- (0.46154,2.69231);
                        \draw (.5,2.5) -- (0.69231,2.53846) -- (0.65385,2.73077);

                        \node[black, left] at (-3,2) {$A$};
                        \node[black, above right] at (2,3) {$B$};
                        \node[black, below] at (1,0) {$C$};

                        \node[black, above left] at (-.5,2.5) {$c$};
                        \node[black, below left] at (-1,1) {$b$};
                        \node[black, below right] at (1.5,1.5) {$a$};
                        \node[black, left] at (0.73077,1.346155) {$h$};
                    \end{tikzpicture}
                    \caption{A triangle with sides $a$, $b$, $c$, and angles $A$, $B$ and $C$}
                \end{center}
            \end{figure}
            From this, we can see that $\sin A=\frac{h}{b}$, using the rules of right angled \\ trigonometry ($\sin\theta=\frac{O}{H}$).
            Thus, $b\sin A=h$.
            Using the same logic for the other right angled triangle, we can also derive $a\sin B=h$.
            We can now set the two expressions equal to each other to find:
            \begin{equation*}
                \begin{aligned}
                    b\sin A&=a\sin B \\
                    \frac{a}{\sin A}&=\frac{b}{\sin B}
                \end{aligned}
            \end{equation*}
            We can now use another line from $B$ to $AC$ to do the same process with angles $A$ and $C$ to prove that $\frac{a}{\sin A}=\frac{c}{\sin C}$, and thus:
            \begin{equation}
                \frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}
            \end{equation}
        \end{proof}

        The sine rule can be used to find missing sides by rearranging for $a$, $b$ or $c$, or all of the fractions can be flipped to put the sine rule in the form:
        \begin{equation}
            \frac{\sin A}{a}=\frac{\sin B}{b}=\frac{\sin C}{c}
        \end{equation}
        Which can then be further rearranged to find a angle, e.g.:
        \begin{equation}
            A=\arcsin\left(\frac{a\sin B}{b}\right)
        \end{equation}

    \subsection{The Cosine Rule}
        \begin{theorem}[Cosine Rule] \label{thm:cosine_rule}
            The cosine rule states the, for a triangle with sides $a$, $b$, $c$, and angles $A$, $B$, $C$ opposite to the corresponding side ($A$ oppsite to $a$, etc.), the following holds:
            \begin{equation}
                a^2=b^2+c^2-2bc\cos A
            \end{equation}
        \end{theorem}
        \begin{proof}
            We will begin by drawing the triangle described in \ref{thm:cosine_rule}, with a line with length $h$ from $C$ to $AB$, meeting $AB$ at a right angle, and splitting it into length $x$ and $c-x$:
            \begin{figure}
                \begin{center}
                    \begin{tikzpicture}[x=15mm, y=15mm, >=stealth]
                        \draw (-3,2) -- (2,3) -- (1,0) -- (-3,2);
                        \draw[dashed] (1,0) -- (0.46154,2.69231);
                        \draw (.5,2.5) -- (0.69231,2.53846) -- (0.65385,2.73077);

                        \node[black, left] at (-3,2) {$A$};
                        \node[black, above right] at (2,3) {$B$};
                        \node[black, below] at (1,0) {$C$};

                        \node[black, above left] at (-1.26923,2.34616) {$x$};
                        \node[black, above left] at (1.23077,2.84616) {$c-x$};
                        \node[black, below left] at (-1,1) {$b$};
                        \node[black, below right] at (1.5,1.5) {$a$};
                        \node[black, left] at (0.73077,1.346155) {$h$};
                    \end{tikzpicture}
                    \caption{A triangle with sides $a$, $b$, $c$, and angles $A$, $B$ and $C$}
                \end{center}
            \end{figure}
            From here, we can use the Pythagorean theorem to see that $b^2-x^2=h^2$ and that $a^2-(c-x)^2=h^2$.
            Setting them equal to each other and rearranging, we get:
            \begin{equation*}
                \begin{aligned}
                    b^2-x^2&=a^2-(c-x)^2 \\
                    b^2-x^2&=a^2-c^2+2cx-x^2 \\
                    b^2&=a^2-c^2+2cx
                \end{aligned}
            \end{equation*}
            Using the rules of right angled trigonometry ($\cos\theta=\frac{A}{H}$), we can see that $\cos A=\frac{x}{b}$ thus $x=b\cos A$, which we can substitute into $b^2=a^2-c^2+2cx$ to get:
            \begin{equation}
                b^2=a^2-c^2+bc\cos A
            \end{equation}
            Which can be rearranged into:
            \begin{equation}
                a^2=b^2+c^2-2bc\cos A
            \end{equation}
        \end{proof}

    \subsection{The Area of a Triangle}
        \begin{theorem} \label{thm:area_of_triangle}
            For a triangle with two sides $a$ and $b$, with an angle $C$ in between them, the area of the triangle is given as:
            \begin{equation}
                A_r=\half ab\sin C
            \end{equation}
        \end{theorem}
        \begin{proof}
            We will begin by drawing the triangle described in \ref{thm:area_of_triangle}, with a line with length $h$ from the side $a$ to the opposite vertex, connected to $a$ at a right angle; we will call the side length opposite $C$, $c$:
            \begin{figure}
                \begin{center}
                    \begin{tikzpicture}[x=15mm, y=15mm, >=stealth]
                        \draw (-3,2) -- (2,3) -- (1,0) -- (-3,2);
                        \draw[dashed] (1,0) -- (0.46154,2.69231);
                        \draw (.5,2.5) -- (0.69231,2.53846) -- (0.65385,2.73077);

                        \node[black, left] at (-3,2) {$C$};
                        \node[black, above right] at (2,3) {$B$};
                        %\node[black, below] at (1,0) {$A$};

                        \node[black, above left] at (-.5,2.5) {$a$};
                        \node[black, below left] at (-1,1) {$b$};
                        \node[black, below right] at (1.5,1.5) {$c$};
                        \node[black, left] at (0.73077,1.346155) {$h$};
                    \end{tikzpicture}
                    \caption{A triangle with sides $a$, $b$, and an angle $C$ between them}
                \end{center}
            \end{figure}
            From here, we can use right angled trigonometry to find that:
            \begin{equation}
                \sin C=\frac{h}{b}
            \end{equation}
            And thus:
            \begin{equation}
                b\sin C=h
            \end{equation}
            Now, we can use the more common formula for the area of a triangle:
            \begin{equation}
                \text{area}=\half\text{base}\times\text{perpendicular height}
            \end{equation}
            We will use $h=b\sin C$ as the height, and $a$ as the base, to get:
            \begin{equation}
                A_r=\half(b\sin C)\times a=\half ab\sin C
            \end{equation}
        \end{proof}

        \subsubsection{Trigonometric Graph Transformations}
            Each of the graphs can be transformed using regular graph transformations.

            In the $y$-axis, for a trigonometric function $f(x)$ and a scalar $k$, these are:
            \begin{align}
                F(x)&=f(x)+k \\
                F(x)&=kf(x) \\
                F(x)&=-f(x)
            \end{align}
            In the context of $\sin x$ and $\cos x$, stretching the function in the $y$-axis ($F(x)=kf(x)$) means increasing its amplitude (for $|k|>1$; it decreases the amplitude for $0<|k|<1$).
            Because the amplitude of $\sin x$ and $\cos x$ are 1, this means that $|k|$ will be the amplitude in this context, sometimes written $A$.
            Mirroring the function ($F(x)=-f(x)$) does not change the amplitude, since $|F(x)|=|f(x)|$, but it will shift the phase of the wave.
            Shifting the function in the $y$-axis would move the equilibrium position of the wave (the height at the average of the peaks and troughs).
            
            In the $x$-axis, for a trigonometric function $f(x)$ and a scalar $k$, the transformations are:
            \begin{align}
                F(x)&=f(x-k) \\
                F(x)&=f\left(\frac{x}{k}\right) \\
                F(x)&=f(-x)
            \end{align}
            In the context of $\sin x$ and $\cos x$, stretching the function in the $x$-axis ($F(x)=f\left(\frac{x}{k}\right)$) means increasing its wavelength (for for $|k|>1$; it decreases the wavelength for $0<|k|<1$).
            Because the wavelength of $\sin x$ and $\cos x$ is $360^\circ$, this means that, in this context, $360^\circ k$ would be the wavelength, sometimes written $\lambda$.
            Mirroring the function ($F(x)=f(-x)$) will not change $\sin x$, and negate $\cos x$.
            Shifting the function in the $x$-axis ($F(x)=f(x-k)$) will shift the phase of the wave, meaning that the starting point of the wave ($f(0)$) will be moved.
            In this context, $k$ would be called the phase shift, sometimes written $\Delta\phi$.

            Putting all of these transformations together, we can make a generalised function for a wave:
            \begin{equation}
                F(x)=A\sin(360^\circ \lambda x-\Delta\phi)+e_q
            \end{equation}
            For an amplitude $A>0$, wavelength $\lambda>0$, equilibrium point $e_q$, and phase shift $\Delta\phi$.
            The function would also work using $\cos$ instead of $\sin$; this would shift the phase by $90^\circ$ because $\sin(x)=\cos(x-90^\circ)$.

\section{Trigonometric Equations and Identities} \label{trigonometric_equations_and_inequalities}
    \begin{theorem}
        For all angles $\theta$:
        \begin{equation}
            \sin^2\theta+\cos^2\theta=1
        \end{equation}
    \end{theorem}
    \begin{proof}
        We will start by constructing a right angled triangle with a hypotenuse with length 1:
        \begin{figure}
            \begin{center}
                \begin{tikzpicture}[x=15mm, y=15mm, >=stealth]
                    \draw (-.5,-1) -- (-.5,1) -- (.5,-1) -- (-.5,-1);
                    \draw (-.35,-1) -- (-.35,-.85) -- (-.5,-.85);

                    \node[black, above right] at (0,0) {1};
                    %\node[black, below] at (0,-1) {$\cos\theta$};
                    %\node[black, above, rotate=90] at (-.5,0) {$\sin\theta$};
                \end{tikzpicture}
                \caption{A triangle with a hypotenuse with length 1}
            \end{center}
        \end{figure}
        Adding an angle $\theta$, we can give the side lengths as $\sin\theta$ and $\cos\theta$:
        \begin{figure}
            \begin{center}
                \begin{tikzpicture}[x=15mm, y=15mm, >=stealth]
                    \draw (-.5,-1) -- (-.5,1) -- (.5,-1) -- (-.5,-1);
                    \draw (-.35,-1) -- (-.35,-.85) -- (-.5,-.85);

                    \node[black, above right] at (0,0) {1};
                    \node[black, below] at (0,-1) {$\cos\theta$};
                    \node[black, above, rotate=90] at (-.5,0) {$\sin\theta$};

                    \draw[black] (.41056,-.82111) arc[start angle=150, end angle=180, radius=.35];
                    \node[black] at (.24480,-.84229) {$\theta$};
                \end{tikzpicture}
                \caption{A triangle with a hypotenuse with length 1 and angle $\theta$}
            \end{center}
        \end{figure}
        Then, using Pythagoras' theorem, we can see that $\sin^2\theta+\cos^2\theta=1$.
    \end{proof}
    Rearranging this identity, we can also use the forms:
    \begin{align*}
        \sin^2\theta&=1-\cos^2\theta \\
        \cos^2\theta&=1-\sin^2\theta \\
        \sin\theta&=\sqrt{1-\cos^2\theta} \\
        \cos\theta&=\sqrt{1-\sin^2\theta}
    \end{align*}

    \begin{theorem}
        The tangent function can be written as a ratio of sine and cosine:
        \begin{equation}
            \tan\theta=\frac{\sin\theta}{\cos\theta}
        \end{equation}
    \end{theorem}
    \begin{proof}
        Using SOH-CAH-TOA, we know that $\sin\theta=\frac{O}{H}$, $\cos\theta=\frac{A}{H}$ and $\tan\theta=\frac{O}{A}$.
        From these, we can find that:
        \begin{align*}
            H\sin\theta&=O \\
            H\cos\theta&=A \\
            \tan\theta&=\frac{H\sin\theta}{H\cos\theta} \\
            &=\frac{\sin\theta}{\cos\theta}
        \end{align*}
    \end{proof}

    \subsection{CAST Diagrams}
        A CAST diagram is used to determine whether sine, cosine and tangent are positive or negative in each quadrant.
        Looking at the graphs, we can see that:
        \begin{itemize}
            \item in quadrant 1 ($\theta\in(0^\circ,90^\circ)$), all three functions are positive.
            \item in quadrant 2 ($\theta\in(90^\circ,180^\circ)$), only $\sin\theta$ is positive.
            \item in quadrant 3 ($\theta\in(180^\circ,270^\circ)$), only $\cos\theta$ is positive.
            \item in quadrant 4 ($\theta\in(270^\circ,360^\circ)$), only $\tan\theta$ is positive.
        \end{itemize}
